# SoundFinder v1.1.2

## English

The first downloadable release of SoundFinder for Alfred: find apps and processes
with active audio output, identify Chrome audio tabs without a browser extension,
and jump to the source.

### Download

- `SoundFinder-1.1.2-arm64.alfredworkflow` — prebuilt installer for Apple Silicon Macs.
- `SHA256SUMS.txt` — SHA-256 checksum for the installer.

Double-click the installer and confirm import in Alfred, then type `sound`.
You do not need Swift, Python, or Xcode to use the prebuilt workflow.

### Included

- Core Audio app/process detection, output device information, and PID filtering.
- Chrome playing/muted tab detection through native Accessibility labels.
- Existing app/tab activation, with target revalidation and frontmost-process checks.
- A dedicated SoundFinder icon, English/Chinese documentation, and a labeled demo mockup.
- The Return-key focus fix from v1.1.1.

### Requirements and limitations

- macOS 14.4+ and Alfred 5 with Powerpack.
- This installer is **arm64 only**. It is not a universal or tested Intel build.
- Chrome tab detection requires Accessibility permission and English Chrome audio markers.
- The workflow UI and messages remain in Simplified Chinese.
- An active output stream can contain silent data; muted tabs are labeled separately.
- Collapsed/hidden windows, multiple profiles, and special windows are not exhaustively tested.
- The executable is ad-hoc signed, not Apple-notarized.
- No recording, audio sampling, background service, extension, or remote debugging is used.

Build validation: 19 Swift tests and 10 package tests passed; code signature and
installer structure checked. The installer is built from the commit targeted by this release.

## 简体中文

SoundFinder 首个提供直接下载安装包的版本：定位 Mac 上活跃音频输出的应用和进程，
无需 Chrome 扩展即可识别发声/静音标签页，并跳转到声音来源。

### 下载

- `SoundFinder-1.1.2-arm64.alfredworkflow`：Apple Silicon Mac 预编译安装包。
- `SHA256SUMS.txt`：安装包 SHA-256 校验文件。

双击安装包，在 Alfred 导入窗口确认后输入 `sound` 即可使用。
使用预编译包无需安装 Swift、Python 或 Xcode。

### 包含功能

- Core Audio 应用/进程检测、输出设备信息和 PID 筛选。
- 通过原生辅助功能标签识别 Chrome 发声/静音标签页。
- 跳转到已有应用/原标签页，重新核对目标并检查实际前台进程。
- 专属图标、双语 README 和明确标注为示意图的产品演示。
- v1.1.1 的回车焦点切换修复。

### 环境与限制

- macOS 14.4+，Alfred 5 + Powerpack。
- 安装包仅支持 **arm64 / Apple Silicon**，不是通用或已验证的 Intel 版本。
- Chrome 标签页检测需要辅助功能权限，目前仅识别英文 Chrome 音频标记。
- 工作流界面和提示仍为简体中文。
- 输出流活跃可能是静默数据；已静音标签会单独标注。
- 折叠/隐藏窗口、多配置文件和特殊窗口尚未完整覆盖验证。
- 二进制采用 ad-hoc 签名，未经过 Apple 公证。
- 不录音、不采样音频、不常驻后台、不安装扩展、不启用远程调试。

构建验证：19 项 Swift 测试、10 项安装包测试通过，已检查签名和安装包结构。
安装包基于本 Release 指向的代码提交构建。

### 校验 / Verify

Download both assets into the same directory / 将两个附件下载到同一目录，然后执行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```
