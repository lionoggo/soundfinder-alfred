# SoundFinder v1.2.0 — Bilingual UI / 双语界面

## English

SoundFinder now supports English and Simplified Chinese for result descriptions,
copied details, permission prompts, error messages, and activation notifications.

### What's new

- **UI language selection:** open Configure Workflow → UI language / 界面语言.
  Choose Auto (macOS), English, or 简体中文.
- **Automatic language:** follows the first macOS preferred language. Simplified
  Chinese uses Chinese; other languages use English.
- **Bilingual setup:** configuration fields, import help, and initial scanning
  prompts are bilingual. The notification title is SoundFinder.
- App names, device names, tab titles, and raw system data are preserved.
- Updated English/Chinese README, download links, and demo disclaimer.

### Download and upgrade

- `SoundFinder-1.2.0-arm64.alfredworkflow` — Apple Silicon installer.
- `SHA256SUMS.txt` — SHA-256 checksum for the installer.

Double-click the installer and confirm the update in Alfred, then run `sound`.
This updates the existing workflow (same bundle ID). Choose your preferred UI
language in Configure Workflow; it applies on the next invocation.
Swift, Python, and Xcode are not needed to run the prebuilt installer.

### Requirements and unchanged limitations

- macOS 14.4+; Alfred 5 with Powerpack.
- Prebuilt installer is **arm64 only**; Intel compatibility is not tested.
- Chrome tab detection still requires **English Chrome audio markers** and
  Accessibility permission. Workflow UI language does not change this requirement.
- Active output streams can contain silent data; muted Chrome tabs are separate.
- Collapsed/hidden windows, multiple profiles, and special windows are not
  exhaustively tested.
- Ad-hoc signed, not Apple-notarized.
- No browser extension, remote debugging, recording, or background service.

Validation: 26 Swift tests and 15 package/runtime checks passed, including both
languages, safe activation failures, argument passing, and Return connections.
The installer is built from the commit targeted by this release.

## 简体中文

SoundFinder 的结果说明、复制详情、授权提示、错误消息和跳转通知现已支持英文及简体中文。

### 更新内容

- **界面语言选择：**在 Configure Workflow → UI language / 界面语言中，
  选择 Auto (macOS) / 跟随系统、English 或 简体中文。
- **自动选择：**跟随 macOS 的第一首选语言；简体中文显示中文，其他语言显示英文。
- **双语设置界面：**配置项、导入帮助和初始检测提示使用双语；通知标题统一为 SoundFinder。
- 应用名、设备名、网页标题及原始系统信息保持原样。
- 更新双语 README、下载入口及演示图说明。

### 下载与升级

- `SoundFinder-1.2.0-arm64.alfredworkflow`：Apple Silicon 安装包。
- `SHA256SUMS.txt`：安装包的 SHA-256 校验文件。

双击安装包，在 Alfred 中确认更新后输入 `sound`。
本版沿用相同 bundle ID，更新已有工作流。在工作流配置中选择界面语言，下次运行时生效。
使用预编译包无需 Swift、Python 或 Xcode。

### 环境与保留的限制

- macOS 14.4+；Alfred 5 + Powerpack。
- 安装包仅支持 **arm64 / Apple Silicon**，Intel 兼容性尚未验证。
- Chrome 标签页检测仍要求 **英文 Chrome 的声音标记**与辅助功能权限；
  工作流的中英文界面选择不会改变该要求。
- 活跃输出流可能包含静默数据；Chrome 已静音标签单独显示。
- 折叠/隐藏窗口、多配置文件和特殊窗口尚未完整验证。
- 二进制采用 ad-hoc 签名，未经 Apple 公证。
- 无需浏览器扩展或远程调试，不录音、不常驻后台。

验证：26 项 Swift 测试、15 项安装包及程序运行检查通过，
覆盖双语输出、安全跳转失败提示、参数传递和回车连接。
安装包基于本 Release 指向的代码提交构建。

### 校验 / Verify

Download both assets to the same directory / 将两个附件下载到同一目录，然后执行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```
